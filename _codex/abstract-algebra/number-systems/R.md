{% entry DEF-1 %}

The **real number system** $\R$ is, up to isomorphism, the unique ordered field that is Dedekind-complete.

  The existence of such a field can be shown through construction. See for example [Construction of the real numbers (Wikipedia)](https://en.wikipedia.org/wiki/Construction_of_the_real_numbers) and its references.

{% endentry %}

{% entry DEF-2 %}

Based on the construction method, $\Q$ can be embedded into $\R$. Then we can say

$$ \N \subseteq \Z \subseteq \Q \subseteq \R. $$

{% endentry %}

{% entry DEF-3 %}

The set of **non-zero real numbers** is

$$ \R^* = \R \setdif \{0\}. $$

{% endentry %}

{% entry DEF-4 %}

The set of **positive real numbers** is

$$ \R^+ = \{x \in \R : x > 0\}. $$

{% endentry %}

{% entry DEF-5 %}

The set of **negative real numbers** is

$$ \R^- = \{x \in \R : x < 0\}. $$

{% endentry %}
