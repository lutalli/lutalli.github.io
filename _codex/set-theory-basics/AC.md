{% definition 1 %}

A **choice function** on a set $X$ is a [function](/x/F) on $X$ such that

$$ \forall A \in X : f(A) \in A. $$

{% enddefinition %}

{% axiom 1 "Axiom of Choice ($\AC$)" %}

Every set has a choice function.

{% endaxiom %}

{% theorem 1 %}

$\AC$ is independent of $\ZF$.

{% endtheorem %}

> $\ZF + \AC$ is denoted by $\ZFC$.
