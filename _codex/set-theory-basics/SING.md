{% definition 1 %}

The **singleton** of a set $a$ is

$$ \{a\} = \{a, a\}. $$

{% enddefinition %}

{% theorem 1 %}

For any set $X$,

$$ X \neq \{X\}. $$

{% endtheorem %}

{% proof %}

If $X = \\{X\\}$, then $X \in X$, contrary to [irreflexivity of $\in$](/x/ZF#T1).

{% endproof %}
