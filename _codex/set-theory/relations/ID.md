{% definition 1 %}

The **identity** on a set $X$ is the [binary relation](/codex/REL)

$$ \id_X = \{(x, x) : x \in X\}. $$

{% enddefinition %}

{% proposition 1 %}

For any set $X$, $\id_X$ is also a [function](/codex/F), called the **identity function**. Moreover, $\id_X : X \to X$ is [bijective](/codex/BIJ).

{% endproposition %}
