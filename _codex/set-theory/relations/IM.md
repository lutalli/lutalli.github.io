> {% codex IM#DEF:Image %}
>
> Let $R$ be a binary relation. The **image** of a set $A$ under $R$ is
>
> $$ R[A] = \{y : (\exists x \in A : x \,R\, y)\}. $$
>
> This is a set by [Separation Schema](/codex/ZF#AX-SEP):
>
> $$ R[A] \subseteq \im R. $$

> {% codex IM#DEF-PRE:Preimage %}
>
> Let $R$ be a binary relation. The **preimage** of a set $B$ under $R$ is $R^{-1}[B]$.

- *Preimage* is also known as *inverse image*.
