{% entry DEF-1 %}

The **singleton** of a set $a$ is

$$ \{a\} = \{a, a\}. $$

{% endentry %}

{% entry PROP-1 %}

For any set $X$,

$$ X \neq \{X\}. $$

{% endentry %}

***Proof.*** If $X = \\{X\\}$, then $X \in X$, contrary to [irreflexivity of $\in$](/codex/ZF#PROP-1).<qed />
