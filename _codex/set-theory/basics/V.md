{% entry DEF-1 %}

The **universal class** is the [class](/codex/CLS) of all sets:

$$ \V = \{x : x = x\}. $$

{% endentry %}

{% entry PROP-1 %}

$\V$ is a [proper class](/codex/CLS#DEF-3).

{% endentry %}

{% proof %}

Since $\V = \V$, it follows that $\V \in \V$, contrary to [irreflexivity of $\in$](/codex/ZF#PROP-1).

{% endproof %}
