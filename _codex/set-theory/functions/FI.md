> {% codex FI#DEF:Inverse Function %}
>
> If $f$ be an injection, then the converse $f^{-1}$ is also a function and is called the **inverse** of $f$.

---

> {% codex FI#PROP-ID %}
>
> For any injection $f$:
>
> {:.par-upper-roman}
> 1. $$ f \circ f^{-1} = \id_{\ran f}. $$
>
> 2. $$ f^{-1} \circ f = \id_{\dom f}. $$
