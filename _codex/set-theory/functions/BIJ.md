{% entry DEF-1 %}

A **bijective function** or **bijection** is a function that is both injective and surjective.

The set of all bijections from a set $X$ onto a set $Y$ is denoted by

$$ \bij(X, Y). $$

{% endentry %}

***Note.*** A *bijection* is also known as *one-to-one correspondence*.
