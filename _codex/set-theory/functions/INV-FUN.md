date:    2026-02-22

{% entry DEF-1 %}

For any injection $f$, its converse $f^{-1}$ is also a function, called its **inverse**.

{% endentry %}

---

{% entry PROP-1 %}

For any injection $f$:

{:.par-upper-roman}
1. $$ f \circ f^{-1} = \id_{\im f}. $$

2. $$ f^{-1} \circ f = \id_{\dom f}. $$

{% endentry %}
