> {% codex ADST#DEF:Antidistributive Function %}
>
> Let $f$ be a function on a set $X$ and $\*$ be a binary operation on $X$. $f$ is **antidistributive** over $\*$ if for all $x$, $y \in X$,
>
> $$ f(x * y) = f(y) * f(x). $$
