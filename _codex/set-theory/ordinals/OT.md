{% entry DEF-1 %}

Every [well-ordered](/codex/WO) set $W$ is [isomorphic](/codex/OH) to a unique [ordinal number](/codex/ORD). This unique ordinal number is called the **order type** of $W$ (with respect to the given well-order).
