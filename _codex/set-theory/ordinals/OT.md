{% proposition 1 %}

Every [well-ordered](/codex/WO) set $W$ is [isomorphic](/codex/OH) to a unique [ordinal number](/codex/ORD).

{% endproposition %}

{% definition 1 %}

This unique ordinal number is called the **order type** of $W$ (with respect to the given well-order).

{% enddefinition %}
