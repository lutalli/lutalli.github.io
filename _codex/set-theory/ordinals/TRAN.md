{% definition 1 %}

A set $T$ is **transitive** if every element of $T$ is a subset of $T$.

{% enddefinition %}

{% proposition 1 %}

The following statements are equivalent:

{:.par-upper-roman}
1. <p style="text-align: center">$T$ is transitive.</p>

2. $$ \bigcup T \subseteq T. $$

3. $$ T \subseteq \powerset(T). $$

{% endproposition %}
