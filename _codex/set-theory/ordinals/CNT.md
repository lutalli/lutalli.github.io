{% entry DEF-1 %}

Let $X$ be a set.

- $X$ is **countable** if there is an injection from $X$ to $\N$.

- $X$ is **countably infinite** if there is a bijection from $X$ to $\N$.

- $X$ is **uncountable** if it is not countable.

{% endentry %}

***Examples.***

1. All finite sets are countable.
2. $\N$ is countable, and countably infinite.
3. $\R$ is uncountable.
