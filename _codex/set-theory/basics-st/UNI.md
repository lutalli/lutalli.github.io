> {% codex UNI#DEF:Universal Class %}
>
> The **universal class** is the class of all sets:
>
> $$ \V = \{x : x = x\}. $$

---

> {% codex UNI#PROP-PC %}
>
> $\V$ is a proper class.

***Proof.*** Since $\V = \V$, it follows that $\V \in \V$, contrary to [ZF#PROP-SLF](/codex/ZF#PROP-SLF).<qed />
