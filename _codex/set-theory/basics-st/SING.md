> {% codex SING#DEF:Singleton %}
>
> The **singleton** of a set $a$ is
>
> $$ \{a\} = \{a, a\}. $$

---

> {% codex SING#PROP-SLF %}
>
> For any set $X$,
>
> $$ X \neq \{X\}. $$

***Proof.*** If $X = \\{X\\}$, we would have $X \in X$, contrary to [ZF#PROP-SLF](/codex/ZF#PROP-SLF).<qed />
