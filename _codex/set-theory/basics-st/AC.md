> {% codex AC#DEF-CF:Choice Function %}
>
> Let $X$ be a non-empty set. A **choice function** on $X$ is a function on $X$ such that
>
> $$ \forall A \in X : f(A) \in A. $$

> {% codex AC#AX:Axiom of Choice %}
>
> Any non-empty set has a choice function.

- Axiom of Choice is denoted by $\AC$.
- $\ZF+\AC$ is denoted by $\ZFC$.

---

> {% codex AC#PROP-ZF %}
>
> $\AC$ is [independent](https://en.wikipedia.org/wiki/Independence_(mathematical_logic)) of $\ZF$.
