{% proposition 1 %}

For every [ordinal](/codex/ORD) $\alpha$ there is a [cardinal](/codex/CARD) greater than $\alpha$.

{% endproposition %}

{% definition 1 %}

The **cardinal successor** of an ordinal $\alpha$, denoted by $\alpha^+$, is the least cardinal greater than $\alpha$.

{% enddefinition %}
