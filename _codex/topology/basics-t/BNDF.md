title:   Bounded Mapping
date:    2026-05-07
updated: 2026-06-20
---

{% entry DEF-1 %}

Let $X$ be a non-empty set and $Y$ be a metric space. A function $f : X \to Y$ is **bounded** if $\im f$ is bounded.

We write

$$ \fun_\text{bd}(X, Y) = \{f \in \fun(X, Y) : \text{$f$ is bounded}\}. $$
