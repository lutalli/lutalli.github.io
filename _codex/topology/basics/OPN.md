---
title:   Open Set
date:    2026-05-07
updated: 2026-06-20
---

{% definition 1 %}

Let $X$ be a metric space and $Y \subseteq X$. $Y$ is **open** if

$$ Y = \inter Y. $$

{% enddefinition %}

{% proposition 1 %}

Let $X$ be a metric space. If $\mathcal{S}$ is a set of open sets from $X$, then $\bigcap \mathcal{S}$ is open.

{% endproposition %}
