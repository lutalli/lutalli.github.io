---
title:   Closed Set
date:    2026-05-07
updated: 2026-06-20
---

{% entry DEF-1 %}

Let $X$ be a metric space and $Y \subseteq X$. $Y$ is **closed** if $X \setdif Y$ is open.

{% endentry %}

{% entry PROP-1 %}

Let $X$ be a metric space. If $\mathcal{S}$ is a set of closed sets from $X$, then $\bigcap \mathcal{S}$ is closed.

{% endentry %}
