{% definition 1 %}

Let $\* : X \times X \to Y$ be a [binary function](/x/F).

- $\*$ is **left-cancellative** if for all $a$, $x$, $y \in X$,

  $$ a * x = a * y \enspace\rimp\enspace x = y. $$

- $\*$ is **right-cancellative** if for all $a$, $x$, $y \in X$,

  $$ x * a = y * a \enspace\rimp\enspace x = y. $$

- $\*$ is **cancellative** if it is both left- and right-cancellative.

{% enddefinition %}
