{% definition 1 %}

Let $f : X \to Y$ be a [function](/x/F) and $A \subseteq X$. $A$ is **closed** under $f$ if

$$ \forall x \in A : f(x) \in A. $$

{% enddefinition %}

{% theorem 1 %}

Any set $X$ is closed under an [operation](/x/OP) on $X$.

{% endtheorem %}

{% proof %}

By [definition](/x/OP#D1).

{% endproof %}
